# Portfolio

Personal portfolio for Karthik Kulkarni — backend engineer working on payment and banking systems.

Live: https://kartik1502.github.io/portfolio/

## Stack

Next.js 16 (App Router, static export), TypeScript, Tailwind CSS, shadcn/ui.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
BASE_PATH=/portfolio NEXT_PUBLIC_BASE_PATH=/portfolio npm run build
```

The static export is written to `out/`.

## Content

- `src/lib/portfolio-data.ts` — profile, projects, experience, writing, and the manual changelog history
- `src/components/` — page sections
- `public/` — images and the generated WakaTime, GitHub contribution, and changelog snapshots

The weekly stats workflow refreshes WakaTime, GitHub contribution, and changelog data, then triggers a deploy.

## Changelog data

The changelog merges three sources:

- `src/lib/portfolio-data.ts` — the manual Arya Banking history through 2026-09-14.
- `public/changelog-arya.json` — one AI summary per day from commits on the default branches of the Arya Banking repositories, generated by `scripts/fetch-arya-changelog.mjs`.
- `public/changelog-contributions.json` — one entry per important external pull request, generated by `scripts/fetch-contributions.mjs` from the PR body.

### Arya AI summaries

Set `GROQ_API_KEY` to a Groq API key. The script uses `openai/gpt-oss-120b` on the free tier. Without the key, or when the API fails, it writes a fallback summary from the commit messages.

The script starts after 2026-09-14 and processes complete days in Asia/Kolkata. It skips dates already in the file. Fallback entries are regenerated automatically when `GROQ_API_KEY` is set; delete an AI entry before you regenerate it:

```bash
GITHUB_TOKEN="$(gh auth token)" GROQ_API_KEY="..." \
  node scripts/fetch-arya-changelog.mjs
```

Set `DRY_RUN=1` to print the result without writing the file.

### External PR entries

```bash
GITHUB_TOKEN="$(gh auth token)" node scripts/fetch-contributions.mjs
```

The script also refreshes `public/contributions.json` for the Open Source section. It adds PRs listed in `include` even when their type would normally be skipped.

### Overrides

`data/changelog-overrides.json` adjusts generated entries:

```json
{
  "include": ["external:owner/repo#123"],
  "exclude": ["arya:2026-10-14"],
  "replace": {
    "arya:2026-10-16": {
      "title": "Custom title",
      "description": "Custom summary."
    }
  }
}
```

- `include` adds an external PR that the type filter skipped.
- `exclude` hides an entry.
- `replace` overrides fields.

The weekly workflow never edits this file.

### Commit and PR contracts

- Arya Banking: add a `Changelog:` trailer to each commit that changes behaviour. Use `Changelog: skip` for documentation, tests, CI, formatting, and dependency bumps.
- External repositories: add a `## Changelog` section to the PR body with `Summary`, `Area`, and `Importance`. Set `Importance: skip` for non-user-facing changes.

The local `AGENTS.md` files hold the same instructions.
